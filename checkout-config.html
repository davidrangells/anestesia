6Order bump e upsell

Configure em Checkout → Order bump. Sugestão: oferecer o upgrade para o plano superior no momento da compra.

1

No checkout do Plano ME/TEA

Exibir order bump oferecendo upgrade para o Plano TSA pela diferença de valor (R$ 350). Texto sugerido: "Adicione o módulo TSA por mais R$ 350 — acesso completo para os três exames."

2

Página de obrigado (thank you page)

Redirecionar para uma página personalizada ou usar a padrão da Eduzz. Incluir instruções de acesso e link direto para anestesia-questoes-aluno.vercel.app.

3

E-mail pós-compra

Configurar sequência automática: e-mail de boas-vindas imediato + lembrete de acesso em 24h. Incluir link de suporte pelo WhatsApp (15) 99100-8159.
